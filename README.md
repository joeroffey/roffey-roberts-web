# Roffey-Roberts Web

The website for [www.roffey-robertsweb.co.uk](https://www.roffey-robertsweb.co.uk): a hand-built static site with no frameworks and no dependencies. Pages are generated by a small Node script, so the output is plain HTML, one CSS file and one small JavaScript file. That keeps it about as fast as a website can be.

Design: dark and luminous, laid out like a printed annual. One axis organises every page: headings and reading columns hang from one third of the way across, and the first third holds the hero's talk, side headings and notes. Bricolage Grotesque for display, Inter for everything else, a violet-to-cyan accent kept for the primary action, the logo and the hero's last two words; everything else is flat colour in solid blocks with square corners. The homepage hero shows the studio's real client sites one at a time, cropped by the bottom edge, with a caption block that links to the case study; the comparison set, the phone mosaic with two figure tiles, the names in columns, the four stages as one bar, the questions as reading text, the inverted close and the name-first footer follow a direction sheet dealt by the `design-taste-frontend` skill (`.taste-skill/direction.json`, ignored by git).

Motion: each headline line rises from behind its own baseline on load (CSS, no script needed); spring entrances, press feedback and the hero picture's scroll drift come from [Motion](https://motion.dev); stacking case-study cards use CSS scroll timelines on desktop. Under `prefers-reduced-motion` nothing starts hidden.

The one third-party file is `static/js/motion.js`: a tree-shaken Motion 14.6.0 build (`animate`, `inView`, `scroll`, `stagger`, `hover`, `press`, about 29 KB gzipped), loaded with `defer`. To rebuild it: `npm i motion esbuild` in a scratch folder, then bundle `export { animate, inView, scroll, stagger, hover, press } from "motion"` with `esbuild --bundle --minify --format=iife --global-name=Motion`. Without it, or with reduced motion requested, the site falls back to plain CSS transitions.

## Editing content

| What | Where |
| --- | --- |
| Contact email, phone, social links, tracking IDs | `src/data/site.mjs` |
| Services (all copy, FAQs, page titles and descriptions) | `src/data/services.mjs` |
| Case studies | `src/data/work.mjs` |
| Local area pages (Southampton, Portsmouth, Winchester, Bournemouth, New Forest) | `src/data/areas.mjs` |
| Homepage | `src/pages/home.mjs` |
| About, contact, privacy, 404 | `src/pages/misc.mjs` |
| Header, footer, `<head>` and structured data | `src/lib/layout.mjs` |
| Logo (the double-R monogram, one continuous line) | `src/data/logo-path.txt`, `static/logo.svg`, `static/favicon.svg` |
| Styles | `static/css/site.css` |
| Screenshots of client sites, laptop and phone | `static/img/work/<slug>.webp`, `static/img/work/<slug>-phone.webp` |
| Behaviour (menu, showcase, motion, search preview, form, consent) | `static/js/site.js` |

Push to `main`, then deploy from Vercel (Project → Deployments → Create deployment, or `vercel --prod`). Pushes don't trigger a deploy by themselves until the Git integration is connected under Project → Settings → Git.

## Running locally

```bash
node scripts/build.mjs           # builds into dist/
FAKE_SEND=1 node scripts/serve.mjs   # preview on http://localhost:4321, form "sends" without email
```

Share images and icons are generated with Playwright (only needed when titles change):

```bash
npm i -g playwright && npx playwright install chromium
node scripts/build.mjs && node scripts/og.mjs
```

## Enquiry form

`api/contact.js` is a Vercel function that emails each enquiry through [Resend](https://resend.com). Set these in Vercel → Project → Settings → Environment Variables:

| Variable | Required | Example |
| --- | --- | --- |
| `RESEND_API_KEY` | yes | `re_…` |
| `CONTACT_TO_EMAIL` | yes | `you@yourdomain.co.uk` (comma-separate for several) |
| `CONTACT_FROM_EMAIL` | once the domain is verified in Resend | `Roffey-Roberts Web <enquiries@roffey-robertsweb.co.uk>` |
| `CONTACT_AUTOREPLY` | optional | `true` to send customers a confirmation |

Each enquiry email includes the first page the visitor landed on and any campaign details (`utm_*`, `gclid`, `fbclid`), so you can see which ads bring in work.

## Tracking for ads

Add Google Analytics, Google Ads and Meta pixel IDs in `src/data/site.mjs`. When any ID is present, a consent banner appears and nothing loads until a visitor accepts (Google Consent Mode v2 defaults to denied). A successful enquiry fires `generate_lead` in GA4, a Google Ads conversion (if `googleAdsLeadLabel` is set) and `Lead` on the Meta pixel.

## Security headers

`vercel.json` sets HSTS, a strict Content Security Policy, `X-Frame-Options`, `Referrer-Policy` and `Permissions-Policy`. If you add a new third-party script, add its domain to the CSP.
